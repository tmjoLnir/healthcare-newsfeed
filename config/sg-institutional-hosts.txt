# Singapore institutional hosts — the allowlist ask, and the sweep input.
#
# None of these has ever been measured. Every one is refused at CONNECT from
# the environments this project has run in, so the survey in
# docs/asia-sources.md has nothing to say about them beyond "unreachable".
#
# Once they are open, measure them in one command:
#
#     python tools/probe_feeds.py --file config/sg-institutional-hosts.txt
#
# That reports BLOCKED / CHALLENGE / NO FEED / the feed URL per host, so a
# host that is still refused is distinguishable from one that genuinely
# publishes nothing — the distinction the Duke-NUS entry got wrong.
#
# ---------------------------------------------------------------------------
# READ THIS BEFORE ADDING THEM TO AN ALLOWLIST
#
# The entry has to name the `www` host. Ten of these apexes are ALREADY open
# and buy nothing, because each answers 301/308 to its `www` host and a
# redirect target is a separate CONNECT:
#
#     singhealth.com.sg  nuhs.edu.sg  sgh.com.sg  ncid.sg  hsa.gov.sg
#     healthhub.sg  a-star.edu.sg  ntu.edu.sg  asianscientist.com

# (nus.edu.sg is the exception — its apex serves a 200 directly.)
